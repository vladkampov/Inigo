# Security policy

This project is an experimental pre-1.0 app. Only the latest published release
receives fixes. No public release is currently endorsed for sensitive production use.

Please do not report vulnerabilities or sensitive writing in public issues.
Use GitHub private vulnerability reporting:
https://github.com/vladkampov/Inigo/security/advisories/new

Before publication, the owner must enable private vulnerability reporting.
If that route is unavailable, use a private contact on @vladkampov's GitHub
profile. Do not post exploit details publicly while arranging contact.

Include affected version, synthetic reproduction and impact. Never include
credentials or personal/workplace text. We will acknowledge reports when possible;
there is no guaranteed response SLA or bug bounty.

Signed updates must never bypass signature validation. Treat downloaded models,
editor context and local-server responses as untrusted. See docs/releasing.md.
