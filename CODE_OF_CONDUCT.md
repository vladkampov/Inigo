# Community code of conduct

Be respectful, constructive and patient. Welcome people of every background and
experience level. Critique ideas and code, not people.

Harassment, threats, discriminatory language, unwanted sexual attention, doxxing
and publishing private information are not acceptable. Do not post private
messages, workplace drafts, credentials or personal contact details in issues.

Maintainers may edit or remove harmful content and restrict participation.
Use GitHub’s private report-abuse tools for harassment or other platform-policy
violations. For security vulnerabilities, use the private route in SECURITY.md.
There is currently no private maintainer channel for conduct reports. A dedicated
email address is not required for this release. Do not use public issues for
sensitive conduct reports or the vulnerability channel for non-security disputes.

For ordinary bugs, feature requests and feedback, use the repository issue
templates: https://github.com/vladkampov/Inigo/issues/new/choose
