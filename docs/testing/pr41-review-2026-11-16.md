# PR #41 review follow-up — 2026-11-16

Started from PR head `27374eb`, preserving its CI/dependency changes.

## Editor, controller and Undo safety

- 21 targeted tests passed: seven editor-capability tests and fourteen actual
  controller/Undo tests using isolated preferences, a controlled debounce clock,
  injected events, a suspended recognizer and a replacement spy.
- Read-only or failed selection/value capability queries reject capture and
  pre-write replacement. Revocation after capture produces no write. Loss of
  caret access after a write remains unconfirmed, without a blind rollback.
- Covered typing, focus/caret/source changes away and back, exclusions, permission
  loss with and without a notification, disabling, manual-operation cancellation,
  one successful repair and suspension of an unconfirmed field.
- Source ownership is recorded only after a confirmed switch. A failed switch
  and later manual source choices cannot cause Undo to change the layout.

These are deterministic adapter/controller tests, not live editor certification.
The existing signed-candidate, second-Mac and human language-review gates remain.

## Protected text, Unicode and traversal performance

- All 13 layout-conversion tests passed, including HTTP/HTTPS scheme casing,
  exact URL preservation/exclusion from spelling, interior UTF-16 offsets in
  unchanged ZWJ/flag/skin-tone emoji and combining sequences, rejection inside a
  changed grapheme, and existing invalid-surrogate/confidence regressions.
- A 20,000-UTF-16-unit fixture contains 1,428 protected mentions. Conversion and
  word extraction now advance through ordered protected ranges without rescanning
  them per character/word. The fixture checks exact content, caret and word count.
- Ten XCTest samples on the development machine's debug build averaged roughly
  6 ms for conversion and 4 ms for prose extraction, including early warmup
  samples. These are local observations, not cross-device/end-to-end guarantees;
  no timing baseline or hard wall-clock assertion is configured.
