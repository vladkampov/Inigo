# PR #41 additional review follow-up — 2026-11-17

## Invocation policy and spelling scoring

- Undo now passes the current invocation policy to guarded replacement. Readback
  stops if the source becomes excluded during an operation, and the temporary
  style-retention check also respects current exclusions.
- Two regressions verify that excluded Undo performs no text reads/writes and
  policy revocation after a write stops further readback/caret writes.
- Spelling error ranges are sorted once and traversed with a forward cursor.
  Tests cover unsorted/overlapping ranges, UTF-16 prefix offsets, empty evidence,
  and 5,000 misspelled words in a 19,999-unit draft.
- All 13 targeted editor/scoring tests passed. The local debug scoring stress run
  averaged roughly 4 ms over ten samples; there is no hard timing gate or claim
  about other devices or complete request latency.

## Translation follow-up and final checks

- Corrected twelve values across Marathi, Telugu, Ukrainian, Hindi, Arabic, Dutch
  and Turkish: unavailable/invalid status, resume, manual versus automatic access,
  Undo, completing sign-in, reversible mappings and text-free diagnostics.
- Extended curated fixtures from five to seventeen critical messages. A regression
  test restores each of the twelve rejected strings in isolation and confirms the
  checker rejects that specific key. No whole-catalog regeneration was performed.
  Fluent-speaker review remains a separate release gate.
- Full suite: 106 Swift tests, 104 passed and two optional model/server checks
  skipped; macOS spelling/layout integration was enabled. Seven Node tests and
  27 Python tests passed, along with all 24 catalog, version and hygiene checks.
- The staged ad-hoc signed development app passed strict signature verification;
  all seventeen critical messages matched its packaged catalogs.
- The isolated signed native AppKit probe passed replacement, caret restoration,
  exact Undo, later-edit protection and rejection of excluded Undo through the
  production editor implementation. This is component validation, not broad
  native/browser compatibility certification. Existing live-editor, second-Mac
  and human-localization release gates remain.
