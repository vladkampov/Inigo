# Draft starter issues

Create these only after the repository is ready. Assign `good first issue` after
a maintainer confirms scope and provides a reproducible environment.

1. **Review interface wording in a language you use** — labels: good first issue, translation.
   Pick one Localization catalog, preserve placeholders and record native-speaker
   review. Attach synthetic screenshots for changed wording.
2. **Expand multilingual quality fixtures** — labels: help wanted, testing.
   Add synthetic examples in an under-tested language with explicit meaning,
   tone and formatting expectations. Avoid real correspondence.
3. **Document VoiceOver onboarding behavior** — labels: help wanted, accessibility.
   Test keyboard order, shortcut recording, progress and completion on a clean Mac;
   record exact app/OS versions without personal text.
4. **Expand protected-link regression cases** — labels: good first issue, testing,
   editor safety. Add URL punctuation and emoji fixtures to core tests, with
   failing evidence before changing code.
5. **Add RTL layout smoke-test guide** — labels: good first issue, documentation,
   accessibility. Cover Arabic, Persian and Urdu, mixed-direction selections and
   Undo using synthetic content. Avoid claiming native-speaker validation.
